# Kospet Map Maker

Программа делает офлайн-карты для часов **Kospet T4** из открытых данных
[OpenStreetMap](https://www.openstreetmap.org) и рельефа NASA SRTM. Выбираете страну, жмёте
«Собрать карту» — через пару минут получаете две папки, которые копируются на часы так же,
как карты, идущие с ними в комплекте.

Работает на **Windows и Linux**, интерфейс на русском и английском.

---

## Зачем это нужно

Часы поставляются с картами лишь для части стран, и обновлять их нельзя. При этом внутри у них
не карты Google, а обычные данные OpenStreetMap в слегка переупакованном виде. Формат удалось
полностью разобрать (см. [docs/FORMAT.md](docs/FORMAT.md)), так что теперь карту можно собрать
для любого региона и из самых свежих данных OSM — они обновляются каждый день.

## Что попадает на карту

| Слой | Что это | Откуда |
|---|---|---|
| **Дороги** | от автомагистралей до тропинок, с делением на классы (часы рисуют их разными стилями) | OSM |
| **Вода** | озёра, водохранилища, широкие реки, болота, ледники | OSM |
| **Реки и ручьи** *(опция)* | узкие реки, нарисованные в OSM линиями; превращаются в тонкие синие полоски | OSM |
| **Землепользование** | леса, парки, поля, сады, жилые и промышленные кварталы, кладбища, заповедники | OSM |
| **Доп. классы** *(опция)* | луга, тундра, скалы, осыпи, пляжи, плантации — привязаны к уже существующим цветам часов | OSM |
| **Рельеф** | горизонтали через 100 или 50 м | NASA SRTM |

Названий улиц на карте нет — формат часов их не хранит. Подписи есть только у объектов
землепользования (парки, заповедники и т. п.).

## Как пользоваться

1. **Выберите регион.** Начните вводить название в поиске — список берётся с Geofabrik и
   включает страны, а для крупных стран — отдельные области. Можно указать и свой файл `.osm.pbf`.
2. **Отметьте слои.** Если карта получается слишком тяжёлой для часов, снимите галочки с троп,
   проездов и грунтовок — они составляют больше половины всех дорог.
3. **Укажите папку и имя карты.** Имя станет названием папки на часах (`moscow`, `kaliningrad`…).
   Если папка с таким именем уже есть и в ней только файлы карт — она будет перезаписана;
   если там лежит что-то ещё, программа остановится и ничего не удалит.
4. **Нажмите «Собрать карту».** Программа сама скачает данные, обработает их и покажет превью.
5. **Скопируйте на часы обе папки**: `<имя>` и `<имя>-cm` (рельеф) — туда же, где лежат стоковые карты.

Скачанные файлы кэшируются: повторная сборка той же страны не качает всё заново
(OSM обновляется раз в сутки, тайлы высот не меняются).

### Сколько это занимает

Зависит от размера региона. Ориентир: выгрузка OSM ~120 МБ обрабатывается примерно за 1,5 минуты,
карта получается ~125 МБ; тайлы высот — около 10 МБ на квадрат 1°×1° (качаются один раз).

## Установка

### Готовая программа

Скачайте `KospetMapMaker.exe` из раздела [Releases](../../releases) — это один файл,
.NET и ничего другого устанавливать не нужно.

### Сборка из исходников

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```bash
dotnet run -c Release                                                  # запустить
dotnet publish -c Release -r win-x64   --self-contained -o publish/win    # один .exe
dotnet publish -c Release -r linux-x64 --self-contained -o publish/linux
```

### Тесты

```bash
dotnet test tests/KospetMapMaker.Tests
```

Тесты проверяют ядро: формат файлов часов, R-дерево индекса, классификацию тегов, геометрию,
изолинии и весь конвейер OSM на маленьком синтетическом `.osm.pbf` (сравнение с эталонными
файлами). Сеть для них не нужна.

## Командная строка

Для скриптов и серверов есть режим без окна:

```bash
KospetMapMaker --cli --region kaliningrad --out ~/maps
KospetMapMaker --cli --pbf central-fed-district-latest.osm.pbf --out ~/maps --name central --step 50
```

| Ключ | Смысл |
|---|---|
| `--region ID` | регион Geofabrik (`kaliningrad`, `crimean-fed-district`, `central-fed-district` …) |
| `--pbf FILE` | свой файл вместо скачивания |
| `--out DIR` | куда сохранить |
| `--name NAME` | имя папки карты (по умолчанию — из региона) |
| `--step 100\|50` | шаг горизонталей |
| `--no-contours` `--no-rivers` `--no-extra` | отключить рельеф / реки-линии / доп. классы |
| `--no-paths` `--no-service` `--no-tracks` | убрать тропы / проезды / грунтовки |
| `--refresh` | скачать OSM заново, игнорируя кэш |

## Если что-то не так

- **Часы не показывают карту или тормозят.** Скорее всего, слишком большой файл дорог.
  Отключите тропы, проезды и грунтовки — объём упадёт в 2–3 раза.
- **Список регионов не загружается.** Нужен доступ к `download.geofabrik.de`. Можно скачать
  `.osm.pbf` вручную и выбрать «Свой файл».

Перед первой заливкой своей карты сохраните копию того, что уже лежит на часах.

## Ограничения

- **Названия улиц** часы не показывают — формат их не хранит.
- **Море и береговая линия** не рисуются отдельно — как и в стоковых картах.
- **Регионы через линию перемены дат** (восток Чукотки) не поддерживаются.

## Где хранятся данные

| | Windows | Linux |
|---|---|---|
| Кэш загрузок | `%LOCALAPPDATA%\KospetMapMaker\cache` | `~/.local/share/KospetMapMaker/cache` |
| Настройки | `%LOCALAPPDATA%\KospetMapMaker\settings.json` | `~/.local/share/KospetMapMaker/settings.json` |

Кэш можно удалить в любой момент.
